# tugcekarakus.com.tr

Tugce Karakus — kişisel site. Tek dosya: `index.html` (Three.js cdnjs'ten yüklenir, build adımı yok).

**İçerik eklemek:** `index.html` içindeki `ENTRIES` listesine `{ tr, en }` alanlarıyla kayıt ekle. TCM işleri için `org:"tcm"` ve `order` ver (dizinde en üstte çıkar); arka plana alınacak kayıtlar için `archive:true`. Push sonrası Vercel otomatik yayınlar.
